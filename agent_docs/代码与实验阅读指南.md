# 代码与实验阅读指南

本指南将代码文件和可观察实验对应起来。建议从一条完整调用路径入手，再按兴趣
深入单个模块。命令默认从项目根目录运行。

## 实验运行方式

```bash
.venv/bin/python experiments/<实验文件名>.py
```

文件名带 `live` 的实验、`reasoning_replay_ab_experiment.py`，以及需要 `--chat`
或真实 Ollama embedding 的实验要连接本地服务；其他列出的实验是确定性离线实验，
不需要 Ollama。在线实验的输出可能受模型版本、服务状态和抽样范围影响，应把结果
理解为观察而非大规模质量结论。

## 路线 A：从用户输入追到工具结果

### 1. 先观察 AgentLoop

```bash
.venv/bin/python experiments/agent_loop_experiment.py
```

打开 `agent/loop.py` 的 `AgentLoop.run()`，追踪模型调用、最终回答判定、空响应处理、
工具执行和 `max_steps` 终止。该实验使用脚本化模型，输出可重复。

### 2. 看工具执行为什么有独立 Runtime

```bash
.venv/bin/python experiments/tool_executor_experiment.py
.venv/bin/python experiments/schema_validation_experiment.py
.venv/bin/python experiments/tool_capability_experiment.py
```

依次阅读 `runtime/executor.py`、`runtime/validation.py`、`runtime/result.py` 和
`tools/registry.py`。观察模型参数如何先验证、不可用工具如何被拒绝、可预期失败
如何变成 `ToolResult`。

### 3. 看 provider adapter 的职责

阅读 `llm/base.py` 和 `llm/ollama.py`，再查看 `experiments/multiple_tools_experiment.py`。
对照通用 `ToolCall` 与 Ollama 请求/响应转换：provider 协议属于 adapter，通用 Agent
控制流程不需要解析 Ollama wire format。

## 路线 B：从会话记忆追到 JSONL trace

### 1. 看一轮如何进入轨迹

```bash
.venv/bin/python experiments/trajectory_experiment.py
.venv/bin/python experiments/conversation_projection_experiment.py
```

阅读 `agent/state.py` 与 `agent/conversation.py`。注意模型响应和 thinking 可以保留
在 trajectory 中，但空响应和 thinking-only 响应不会因此变成正式对话消息。

### 2. 看跨轮历史的保存和预算

```bash
.venv/bin/python experiments/conversation_memory_experiment.py
.venv/bin/python experiments/history_character_budget_experiment.py
```

阅读 `agent/session.py` 与 `memory/conversation.py`。观察只有成功完成的轮次会提交，
窗口淘汰完整轮次；字符预算影响本轮选取，不删除已保存历史，也不等于 token 预算。

### 3. 看事件、计时和 JSONL 持久化

```bash
.venv/bin/python experiments/structured_trace_timing_experiment.py
.venv/bin/python experiments/jsonl_trace_experiment.py
```

阅读 `observability/events.py`、`observability/metrics.py`、`observability/logger.py`
和 `observability/jsonl.py`。观察同一 run/step 的事件关联方式、耗时单位以及默认不
记录原文的 JSONL 策略。

## 进一步探索长期记忆

```bash
.venv/bin/python experiments/long_term_memory_experiment.py
.venv/bin/python experiments/long_term_retrieval_budget_experiment.py
.venv/bin/python experiments/semantic_memory_experiment.py
```

依次阅读 `memory/long_term.py`、`memory/semantic.py` 和 `llm/embedding.py`。离线
语义实验用固定的几何向量演示余弦排序，不替代真实 embedding 质量评估。在线 smoke
test 及小样本结果见 [Phase 8C 实现记录](./Phase%208C%20-%20SQLite%20语义检索实现记录.md)。

## 查看在线集成场景

需要 Ollama 服务时，可运行：

```bash
.venv/bin/python main.py
```

`main.py` 是连续对话入口，`:help` / `:clear` / `:exit` 是本地命令。调用
`main.py --help` 查看模型、服务地址、日志文件和 trace 参数。会话记忆在线实验、reasoning
replay A/B 和 embedding 实验的前置条件及已知结果分别见对应 Phase 记录。
