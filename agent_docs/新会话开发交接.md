## 2. 当前架构

```text
Application
    │
    ▼
AgentLoop ──→ AgentState / Trajectory
    ├──→ ConversationProjector ──→ canonical messages
    ├──→ ToolExecutor ──→ ToolRegistry ──→ Tool
    ├──→ Observability Events ──→ Logger
    └──→ LLM Interface ──→ OllamaClient
```

Trajectory 事实：

```text
InputMessage
AgentStep
    ├── ModelResponse
    ├── ReasoningBlock | None
    └── ToolExecution(call, result)
```

`ConversationProjector` 只生成 canonical conversation。它不会回放 thinking、
截断历史、生成摘要或使用 memory。

## 3. Phase 6B 的关键结论

### Provider capability

```text
LLM.capabilities.reasoning_replay
    unsupported（默认安全值）
    supported
```

没有显式声明的 adapter 一律不允许 replay。

### Ollama

Ollama 官方 Chat API 把 `thinking` 定义为 message 字段。官方 tool-calling
示例会把包含 thinking 的 assistant message 放回下一轮请求；流式示例也要求
累计 thinking/content/tool_calls 后一起回传。

因此 Ollama adapter 声明：

```text
provider_name = ollama
reasoning replay transport = supported
```

这只表示 API 能传输，不表示 replay 对每个模型都有收益。

### ReasoningBlock

```text
provider
model
raw_thinking
replayable
provider_state
```

每个带 thinking 的 ModelResponse 都会在 AgentStep 中得到一个带 provenance
的 ReasoningBlock。thinking 不会混入 final content。

DecisionMemo 已暂时移除。等 Reasoning Replay 策略通过真实模型实验并成熟
后，再根据实际需求决定是否重新设计 provider-neutral memo。

## 4. 必须保持的不变量

```text
1. 默认 reasoning replay 始终为 off。
2. replayable=True 只表示 adapter 能传输，不表示策略已启用。
3. thinking 不等于最终回答。
4. thinking 不参与权限、参数验证或工具授权。
5. ConversationProjector 保持 policy-free。
6. 不支持 replay 的 provider 安全降级为 canonical messages。
7. provider/model 不匹配时不得回放 ReasoningBlock。
8. raw thinking 不应无限期进入上下文。
```

## 5. Phase 6C 的目标

实现 `ContextBuilder`，统一决定本轮实际发送给模型的上下文。

第一版只支持：

```text
reasoning_replay = off | latest_pending
default = off
```

建议职责：

```text
ConversationProjector
    从 Trajectory 生成 canonical messages

ContextBuilder
    读取 canonical messages、ReasoningBlock、provider capability 和策略
    生成本轮 model context
```

`latest_pending` 必须同时满足：

```text
ReasoningBlock.replayable
provider 与当前 LLM 相同
model 与当前 LLM 相同
是最近一个仍与当前 observation 相关的未完成 step
```

第一版不要试图回放所有历史 reasoning。

## 6. Phase 6C 不要同时实现

```text
自动历史摘要
完整 token-budget manager
短期或长期 memory
DecisionMemo 或其他决策摘要
JSONL trace
权限系统
默认开启 reasoning replay
```

先让 off/latest_pending 的选择可测试，再逐步加入上下文压缩。
