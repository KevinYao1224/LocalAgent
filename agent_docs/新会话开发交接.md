# 新会话开发交接

这是新任务的**短检查单**，不是第二份路线图。现状与优先级以[后续开发路线](./后续开发路线.md)为准。

1. 在仓库根目录运行 `git status --short`；以当前工作树为准，保留他人的未提交改动。
2. 按任务读[当前架构导览](./当前架构导览.md)及[代码与实验阅读指南](./代码与实验阅读指南.md)；需要设计依据时再打开[阶段记录索引](./README.md)中对应的 Phase 文档。
3. 当前默认入口是 `.venv/bin/python main.py`（需 Ollama）；无需模型的可读交互实验是 `.venv/bin/python experiments/interactive_cli_experiment.py`。历史 `main.py --scenario` 已被独立的 `experiments/conversation_memory_live_experiment.py` 替代。
4. 保持关键边界：Trajectory 保存运行事实，ConversationProjector 投影正式消息，ContextBuilder 为单次调用施加策略；`AgentSession` 只提交完成轮次。thinking 不等于正式回答或权限；reasoning replay 默认 `off`。执行时工具必须仍在 `available_tools()` 中，长期检索数据只能作为不可信参考。
5. 完成一个小阶段后运行相关离线可读实验；必要时在 Ollama 可用时做在线验证，并明确样本限制。运行 `.venv/bin/python -m compileall -q agent llm memory runtime tools observability evaluation main.py experiments` 和 `git diff --check`；在 `agent_docs` 更新状态、方案、重要发现与实验方法。

已完成基线：Phase 1—8C（含 7D）、12A—12B、13A—13B 和交互 CLI。下一条**建议**主线为 Phase 9A 最小 Planner；9—11 与 14—15 仍属后续任务。WSL/Ollama 的环境说明见[开发环境指南](./WSL2%20迁移与开发指南.md)。
