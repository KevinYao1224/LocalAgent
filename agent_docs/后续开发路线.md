本页是**唯一的当前阶段状态与待办入口**。模块细节见[当前架构导览](./当前架构导览.md)，实验命令见[代码与实验阅读指南](./代码与实验阅读指南.md)，历史决策见[文档导航](./README.md)。阶段编号表示主题，不保证实现顺序。

## 已实现的基线

| 阶段 | 已有能力 | 边界 |
|---|---|---|
| 1—5 | Ollama tool calling、AgentLoop、ToolExecutor / ToolResult、JSON Schema 参数校验、多工具顺序执行 | 一次响应的多个工具调用仍顺序执行；`max_steps` 防止无限循环 |
| 5.5、6A—6C | 人类可读事件、thinking 捕获、Trajectory、canonical conversation、ContextBuilder | reasoning replay 默认 `off`；`latest_pending` 仅在 capability、来源和 observation 条件满足时可选；thinking 不等于回答或授权 |
| 7A—7D | 完成轮次的短期记忆、跨轮实验、检索时完整轮次字符预算、执行时工具 capability 检查 | 历史预算不是完整 prompt/token 预算；可用工具检查不是完整权限策略 |
| 8A—8C | SQLite namespace 文本记忆、显式检索与字符预算、可替换 embedding 和小规模 cosine top-k | 不自动写入或读取；参考数据不可信；未验证大数据量性能 |
| 12A—12B | run/step ID、UTC 时间、耗时、JSONL v1、RunMetrics | 默认 JSONL 不含原文；它不是 checkpoint |
| 13A—13B | 独立离线评测、Ollama 固定题目重复评测、记忆干扰项 | 脚本通过率不是模型质量；在线小样本不保证显著性 |
| 9A | 显式 CalculatorPlanner：JSON 结构化计划、整份预校验、依赖解析、逐步执行/状态核验 | 不接管默认入口；只支持计算器；无法验证计划是否符合用户意图；非持久化 trace |
| 10A | 可选的有界工具错误恢复：按错误类型分类、限制模型纠正轮数、独立终止原因和决策事件 | 不自动重试 handler，不覆盖模型/Runtime 异常；尚无 Critic 或在线收益对照 |
| 10B | 可选的纠正步骤模型自检提示，Phase 13 评分接口支持恢复策略，脚本预置错误后对 Ollama 做配对小样本对照 | 提示不是独立 Critic；对照未证明收益，默认关闭；异常不自动重试 |
| 11A | 显式注册的只读文本工具：受信任目录、逐段禁 symlink、相对路径、普通文件和字节上限；权限拒绝单独分类 | 默认入口未开放文件工具；不是通用沙箱，不支持命令/网络/写入；需要可信 root 与本地进程隔离 |
| 11B | 显式注册的固定命令动作：完整 argv、cwd、环境、时间与 stdout/stderr 合计字节上限 | 模型不能提供命令参数；默认入口未开放命令；命令仍具 OS 权限及副作用，不是沙箱 |
| 11C | 只读文件可选精确相对路径白名单：配置快照，未授权路径在打开前拒绝 | 不改变默认授权范围；路径名不是文件身份或 OS 隔离 |
| 交互入口 | `main.py` 连续对话、`--prompt`、`:help` / `:clear` / `:exit`、文件调试日志和可选 JSONL | 默认仅计算器和短期会话记忆；长期记忆仍需显式调用 |

Phase 9 计算器范围和 Phase 10 的**有界工具纠正与可选自检/对照**已实现；Phase 11A 覆盖[显式的只读文件权限边界](./Phase%2011A%20-%20只读文件权限边界实现记录.md)，11B 覆盖[固定命令的有界执行](./Phase%2011B%20-%20固定命令有界执行实现记录.md)，11C 覆盖[精确文件资源授权](./Phase%2011C%20-%20精确文件资源授权实现记录.md)。通用沙箱与其余 Phase 11、14—15 尚未实现。Phase 10 不含独立模型 Critic、通用异常自动重试或收益证明；见[10A](./Phase%2010A%20-%20有界工具错误恢复实现记录.md)与[10B](./Phase%2010B%20-%20自检提示与对照评测实现记录.md)。以 `git status --short` 和代码确认后续变化。

## 已完成：Phase 13 Evaluation

现有 Trace 能看到步骤、异常、耗时与已报告 token；Phase 13 已建立可重复的离线基线和可选的在线多次运行：

1. 复用 `ScriptedLLM`、`AgentLoop` 和现有工具，定义少量声明式 case：算术、工具选择和参数、未知工具、无需工具、`max_steps`。
2. 用最终答案、工具调用/参数、`stop_reason` 判定逐例结果；人类可读地输出逐例事实和汇总成功率、步数、工具调用及错误。复用 Phase 12 的耗时与 token 指标，缺失值保持 unknown。
3. 用故意通过和失败的离线 case 验证 runner 本身；**脚本模型通过率不能冒充真实模型质量**。13B 保留每次 run ID、报告重复波动，加入记忆检索的缺失事实/误归因案例。详见[Phase 13 实现记录](./Phase%2013%20-%20Evaluation%20实现记录.md)。

Phase 9A 已以可选路径实现；先运行 `experiments/planner_experiment.py` 看 Phase 13 脚本基线和规划路径，并可选 `experiments/planner_live_experiment.py --repeats 3` 做真实模型小样本对照。见[Phase 9 实现记录](./Phase%209%20-%20Calculator%20Planner%20Executor%20实现记录.md)。Phase 10 离线恢复实验为 `experiments/recovery_experiment.py`；可选在线自检对照为 `experiments/recovery_critic_live_experiment.py --repeats 3`。Phase 11A/B/C 离线实验分别为 `experiments/read_text_permission_experiment.py`、`experiments/fixed_command_permission_experiment.py` 和 `experiments/read_text_allowlist_experiment.py`。后续继续完善 Phase 11 权限前提；不要为演示规划或纠错而提前放开更多副作用工具。

## 已实现模块的后续研究（非当前阻塞项）

- **上下文**：统一计算 system、当前问题、工具 schema、历史及检索内容的预算；有 provider 估算依据后再做 token budget。评估完整轮次摘要的损失；`DecisionMemo` 暂缓，reasoning replay 不默认开启，先在更难的任务上 A/B。
- **长期记忆**：来源关联的分段、显式/自动写入策略与评测、metadata 过滤；测试相似干扰项、缺失事实和预算排除的误归因；规模扩大后再测 SQLite 扫描与过滤成本。不默认跨用户共享。
- **可观测性**：按需要将短期/长期检索选择指标和来源 ID 与 run 关联；并发前给同一步的每次工具调用独立 ID。不要把 JSONL 当可恢复状态。
- **工程约束**：保持 provider-neutral 核心；LLM 输出及检索文本均不授予权限。只在实际需求出现时新增抽象/ADR，不预建大型框架、向量数据库或复杂 UI。

每次增量先回答：它属于哪层、依赖方向是否合理、怎样通过人类可读实验和回归证明它工作；随后把新发现写回本目录。参考原理与实验细节请从[历史记录索引](./README.md)按主题查阅。
